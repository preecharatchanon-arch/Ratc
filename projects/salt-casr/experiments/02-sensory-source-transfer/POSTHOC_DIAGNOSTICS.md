# Diagnostics added after the initial results

The initial designated ExtraTrees result fell below chance under reference-and-similarity grouping. Before interpreting this as failure to transfer, perform the following diagnostics. These were specified after observing that result and are not preregistered primary analyses.

1. Report AUC separately within each held-out fold, with test size and class counts, to check whether pooled scores from different fitted models create the entire result.
2. For each original reference-blocked fold, draw a random test sample of the identical size and class counts, with its complement used for training. This controls training size and class proportion, but permits source/similarity overlap. Fix seed 40000 + original seed + fold. Evaluate only the already designated ExtraTrees model; no tuning.
3. Rebuild reference connectivity after removing two visibly truncated DOI tokens, one malformed DOI token, and four verified secondary-review/model references. Refit the same ExtraTrees model at the original three split seeds. Records with no remaining DOI retain similarity grouping; count and disclose them. This is a sensitivity to citation parsing, not an assertion that all remaining references have been independently verified as primary studies. A fourth review (10.1002/fsh3.12055) was identified during source verification and added before finalizing this diagnostic; no model or hyperparameter was selected from its result.
4. Score the five newly published mushroom peptides with the fixed baselines, trained on either all records or the sensory-tagged subset. Check exact and close-sequence overlap. Retain their standalone-taste descriptors and NaCl-enhancement observations separately. Five author-selected candidates do not constitute a population-level external performance estimate; two less-pronounced effects will not be fabricated into definite negatives.
5. Inspect the 2017 human taste-cell arginyl dipeptide study separately. Cellular NaCl-response enhancement is not the same target as standalone sensory saltiness. Existing benchmark entries are not an independent test of the classifier.
