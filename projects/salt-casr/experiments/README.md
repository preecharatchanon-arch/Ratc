# Research experiments

[Project overview](../README.md) · [Shared data](../data/README.md) · [Current evidence review](../evidence-review/README.md)

This index covers the five completed analyses. The current question and execution gate are in [research status](../docs/RESEARCH_STATUS.md). The [later CaSR follow-up](01-casr-models-and-docking/followups/README.md) preserves additional exploratory comparisons on existing data.

1. [CaSR models and docking](01-casr-models-and-docking/README.md): chemical reconstruction, receptor-activity prediction and reference-pose validation.
2. [Sensory source transfer](02-sensory-source-transfer/README.md): label evidence, sequence/reference holdouts and post-hoc transfer controls.
3. [Assay conditions and dose](03-assay-dose-response/README.md): complete tested panels, dose-ranking reversals and a context-dependent negative label.
4. [TRPV1 membrane access](04-trpv1-membrane-access/README.md): experimental coordinates, membrane boundaries, lipids and a bound peptide comparator.

5. [Functional assay controls](05-functional-assay-controls/README.md): condition-specific human taste-cell outcomes, separate knockdown cohorts and soy sensory/organoid comparators.

Within each experiment, `code/` holds readable scripts, `results/` holds reviewed outputs, and `verification/` holds the original execution records where supplied. Protocols and source manifests sit beside the report. New local outputs go to ignored `runs/latest/` folders. Experiments 01, 02, 03 and 05 include self-contained executed notebooks with embedded inputs and code. The three previously shared notebooks remain unchanged.
